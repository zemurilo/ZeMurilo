## 🌟 Projetos em destaque

### [🎮 Quiz dos Anos 2000](https://github.com/zemurilo/Quiz_Animado)
Quiz interativo em **Java** com sistema de contas de usuário, onde implementei **hash de senhas com SHA-256** (via `MessageDigest`) — as senhas nunca são salvas em texto puro, só o hash. Também inclui validação de senha forte, 50 perguntas sorteadas sem repetição e histórico de pontuações salvo em arquivo com data/hora.

### [🐾 Pokémon Tamagotchi](https://github.com/zemurilo/PokemonTamagotchi)
Simulador em **C#** que consome a PokéAPI de forma assíncrona (`HttpClient` + `async/await`) para buscar dados reais de Pokémon. Tem sistema de status (vida, fome, energia, experiência, nível), persistência em JSON com 3 slots de save, e arquitetura orientada a objetos com responsabilidades bem separadas entre as classes.

## 💡 Experiência prática

- **Segurança/Criptografia** — implementei hash de senhas com **SHA-256** (Java) no projeto Quiz_Animado, armazenando apenas o hash das senhas dos usuários, nunca o texto puro.
- **Consumo de API assíncrono** — no PokemonTamagotchi (C#), busco dados reais da PokéAPI com `HttpClient` e `async/await`, além de (de)serialização JSON com `System.Text.Json`.
- **APIs REST com Spring** — criei um CRUD completo em Spring, com arquitetura em camadas (Controller → Entity → Repository → Service), usando JPA/Lombok e expondo endpoints GET, POST, PUT e DELETE, testados via Postman.
- **Persistência de dados** — conectei a aplicação Spring ao MySQL usando Spring Data JPA, criando as classes de entidade e os repositórios responsáveis por consumir e gravar os dados.
- **Cloud (AWS EC2)** — criei e conectei em uma instância EC2 (t3.micro, us-east-1), configurando grupos de segurança.
- **Servidor web (Linux/Nginx)** — acessei a instância via SSH, naveguei até `/var/www/html/`, editei a página padrão do Nginx com `nano` e reiniciei o serviço com `systemctl`, colocando uma página customizada no ar.
- **POO avançada na prática** — implementei exemplos de **polimorfismo** (array de objetos `Veiculo` chamando `buzinar()` de subclasses distintas como `Carro`, `Moto` e `Bicicleta`) e de **herança + interface combinadas** (hierarquia `Funcionário` com subclasses como `Motorista` e `Analista`, onde só algumas implementam a interface `UsuarioAutenticavel`).
