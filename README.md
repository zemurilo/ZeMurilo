## 💡 Experiência prática

| Área | O que fiz |
|---|---|
| 🔐 **Segurança** | Hash de senhas com SHA-256 (Java) no Quiz_Animado — nunca armazeno senha em texto puro |
| 🌐 **APIs REST com Spring** | CRUD completo em camadas (Controller → Entity → Repository → Service), JPA + Lombok, endpoints GET/POST/PUT/DELETE testados no Postman |
| 🗄️ **Persistência** | Spring Data JPA conectando a aplicação ao MySQL |
| ☁️ **Cloud (AWS EC2)** | Criei e conectei uma instância EC2 (t3.micro, us-east-1), configurando grupos de segurança |
| 🖥️ **Servidor web (Linux/Nginx)** | Acesso via SSH, edição da página padrão do Nginx (`nano`) e gerenciamento do serviço via `systemctl` |
| 🔄 **API assíncrona (C#)** | Consumo da PokéAPI com `HttpClient` + `async/await` e serialização JSON |
| 🧩 **POO avançada** | Polimorfismo (array de `Veiculo` com `Carro`/`Moto`/`Bicicleta`) e herança + interface combinadas (`Funcionário` → `Motorista`/`Analista`, com `UsuarioAutenticavel`) |
